## M1 — kit (FE-pages waits on this; ship pieces as they are ready and ping FE-pages)
1. **Hero card**: rows A–G as one API.
   - Rows: A chips + action slot (links → 🔍 → ✏️), B identity (icon + description; people: name + fact), C main number (full width, semantic colour, optional "/ target"), D bar (pace tick / 25-50-75 ticks / split / limit + caption), E 2–4 tappable tiles, F amber alert line, G embedded slot.
   - **Edit variant**: editable chips as dropdowns, icon ✎, underlined name / description inputs, an outlined amount field on the tint (no white boxes). Rows D–G are hidden.
2. **Section pieces**
   - Tag row under the card, same in view and edit.
   - Info box (no heading). Short text values sit on ONE row (label left, value right); a value that doesn't fit wraps to the stacked look (label above, value below) by itself. Pages never choose.
   - **การตั้งค่า** section: heading + one-line explanation; live toggles and summary rows ›.
   - People strip: member cards + ＋ เชิญ, shared by events and wallets.
   - **โน้ต** section: own box, label stays "โน้ต".
   - **End zone**: ✅ close / 🗄 เก็บถาวร / 🗑 ลบ, each with a one-line consequence.
   - Meta line.
3. **Detail template**
   - Section order: card → tag row → actions → ข้อมูล → การตั้งค่า → คน → โน้ต → records. The note sits after the content and above the record list. With an overview tab, the note is the last section of that tab.
   - Edit mode keeps the same order, hides computed / people sections, and adds the end zone after the note.
   - Enter edit mode with ✏️ or by long-pressing a field (opens focused on it).
4. **Swipe tabs**: labels plus a **page indicator at the end of each tab's content** (in the flow, not floating).
5. **List summary card**: tiles as filters (selected = teal outline), alert line, a big CTA button option.
6. **Shell swipe**: only on the roots of the 4 bottom tabs and the 3 top tabs (pending, notifications, profile / settings). Pages opened on top have none.
7. **Reference page**: rebuild the **categories detail + edit mode** with the new pieces (section 9). It becomes the model FE-pages copies.
   - Its card number "ต.ค. ใช้ไป ฿X · n รายการ ›" uses the BE M1 item 5.
8. **Feature-widget ratchet** (audit in `ai/inbox/fe-a.md`, "Non-shared widgets audit" + "RE-CLASSIFIED": A ≈ 18 · B ≈ 111 · C ≈ 25).
   - Build `test/ui/feature_visuals_test.dart`: counts widgets in `lib/features` / `lib/app` that lay things out themselves; the baseline may only shrink.
   - Do the A duplicates first (switch to the kit piece, delete the copy). B widgets move into the kit as each page is reworked in 0.4.0; your own areas (shell, settings, pending, notifications, categories) go to zero.
9. **l10n words**: รอรับ / รอจ่าย (replace ติดคุณ / คุณติด / ติดเงินคุณ / ได้คืน), ภาพรวม (replace แดชบอร์ด as a detail tab name), ผูกกับ (replace แบ่งรายการ), เก็บถาวร (replace เก็บเข้าคลัง). The note label stays โน้ต.
