# Test diet — cut the Flutter suite to the minimum (2026-10-24)

The owner's rules, 2026-10-24:
- "optimize การเทสให้น้อยที่สุด ไม่งั้นไม่ไหว": the fewest tests, not speed.
- "ขอแค่ logic ถูก แล้ว test ว่าใช้ ui จาก hub ไหม": logic, plus a check that pages use hub UI.
- "เราก็ทำเทสแค่ hub พอจบ": UI is tested only through the hub.

**Status: PROPOSAL (v3). Nothing is deleted yet.** Lead (chubi-pocket-99) audited all 173 files read-only. Cut only on the owner's word.

## What stays
- **UI = the hub only:** `test/hub/hub_pages_smoke_test.dart` renders every hub page, so every kit piece is rendered.
- **Pages use hub UI = 6 source-scan ratchets** in test/ui. They read the code and render nothing, so a UI change doesn't break them; they fail only when a page bypasses the kit.
  - raw_widgets: no raw Material in features
  - feature_visuals: pages don't lay out by hand
  - layering: features import only `ui/ui.dart`
  - hub_coverage: every exported piece is on a hub page
  - hub_duplicates: no piece on two hub pages
  - page_refresh: every detail page wires onRefresh
- **BE contract:** api_spec_ratchet + page_flows.
- **Logic:** plain `test()` / blocTest that pumps no UI: parsing, money math, cubits, request bodies, sync, formatting. Repeated cases are merged into tables.
- **Gone:** every other `testWidgets`, i.e. every page, sheet and kit widget test, with no exceptions.

- **Money saves (12, transactions):** the quick create bodies per mode (tx / debt record / debt settle / saving), tx edit PUT, also_update_link / skip_occurrence, debt entry PUT, recurring link, and no event-mode save test at all. Today these bodies are built INSIDE widgets, so a logic test needs the builder pulled out into a plain function first.
- **Other features (15):** wallet track_balance, archived restore, budgets period writes, contacts show_nickname, notification actions, pending submit filter, event delete scope (owner 2026-10-13), recurring แก้ยอด / ข้าม, saving goals auto-save off, settings PUTs, and others.
- **Shell (7):** back-at-root target, unsaved-edit prompt (EditModeMixin), nav hidden after a fast back (owner 2026-10-12), reload when back online, quick create mode / prefill, swipe-back stack (accept), failed load vs empty.
